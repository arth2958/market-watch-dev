# Local loss-review preview

No private holdings, account identifiers, portfolio-derived symbol lists, file samples or raw historical price dumps belong in this directory or repository.

The only manual-entry/paste processor is `../loss-monitor.html`, in an opaque-origin sandbox (`allow-scripts allow-downloads`, no allow-same-origin). Its CSP denies network connections, forms, objects, images and scripts other than the exact hashed code. Rows render through textContent. Memory-only mode clears on reload/Clear; opt-in device saving restores rows and reprices using the bundle. Parent receives numerical height and explicit device-save messages. Optional device saving is off by default. A validated parent bridge stores only the five-field rows in localStorage, with separate per-project path keys; other scripts on arth2958.github.io could access that same-origin storage. No analytics or server storage. Erase removes saved and memory copies; disabling saving erases the saved copy. Demo rows are not saved.

The fixed public universe uses the third-party S&P constituent dataset and a static ETF list. Yahoo/yfinance adjusted closes produce historical correlations; the published child contains derived top-three matches plus public closing snapshots only, not raw daily history. Coverage and dates are displayed. Highest means highest positive 1-year Pearson correlation in that fixed universe, excluding identical ticker and known same-issuer share classes. It is not a tax or suitability finding.

Build tools are research utilities, not a scheduled workflow. In a private working directory: copy source files and universe.json, install pandas/yfinance, run build_public_data.py, then compose.py (which expects the dev checkout under ./dev). compose.py creates the standalone child and adds the navigation once. Do not commit generated public-market-data.json (raw history). Rebuild requires price/method and content review, sandbox/network/storage tests and mobile/desktop pixel review.

The preview is snapshot-only. No broker feed, wash-sale history ingestion, background notification or daily update schedule is active. The manual form and comma/tab paste accept exactly ticker, acquired, quantity, entry price, side. Edit/Save/Cancel/Remove are supported. Only stock and ETF lots are supported; options are not. Entry data is memory-only unless device saving is explicitly enabled; device storage failures are shown. Publication to production requires a fresh user Go for the reviewed dev revision.
